# Dangerous Ice Rink 🏒❄️

Bienvenue sur le dépôt du projet **Dangerous Ice Rink** développé en Verse pour UEFN (Unreal Editor for Fortnite). Ce projet intègre divers systèmes de gestion et de dispositifs pour une expérience de jeu unique.

## 📁 Structure du projet

Les scripts du projet sont organisés dans le dossier `devices/`:
* **devices/event_manager_device** : Dispositif de gestion des événements pour les animations ou événements temporaires.
* **devices/game_manager** : Gestionnaire principal de la logique du jeu.
* **devices/map_version_display_device** : Gestion de l'affichage de la version de la carte et de la taille de police dans le jeu.
* **devices/player_stats_manager** : Implémentation de la logique de gestion et de suivi persistant des statistiques des joueurs.

## 🚀 Fonctionnalités
* Suivi et sauvegarde des performances des joueurs.
* Gestion dynamique des événements de jeu.
* Affichage des informations de version de la carte en temps réel.

## 🛠️ Utilisation
1. Clonez ce dépôt ou intégrez-le dans votre projet UEFN.
2. Retrouvez les différents appareils dans le dossier `devices/`.
3. Glissez-déposez les scripts dans vos appareils Verse pour les utiliser dans votre niveau.
